# LittleTool

LittleTool 是一个面向开发与运维场景的轻量桌面工具箱，目标是把开发、运维、文档处理中的高频小工具集中到一个本地桌面应用里，做到默认可用、依赖少、启动快、界面清晰。

English version: [README.en.md](./README.en.md)

## 当前目标

- 做一个真正轻量的本地工具箱，而不是大而全的平台
- 优先落地高频刚需工具
- 保持默认中文，同时保留可扩展的 i18n 能力
- 用最少依赖完成大部分基础能力

## i18n

当前 i18n 方案已经调整为可扩展结构，而不是直接把中英文写死在页面组件里。

- 语言包目录：`src/i18n/messages`
- Provider：`src/i18n/I18nProvider.tsx`
- 配置：`src/i18n/config.ts`
- 默认语言：`zh-CN`
- 当前内置语言：
  - `zh-CN`
  - `en-US`

后续增加新语言时，原则上只需要：

1. 新增一个语言文件
2. 在 `i18n/config.ts` 中注册
3. 补充对应文案
